### 二、自建部署教程（把这套小店自己跑起来）

**环境**：Linux 服务器（1 核 1G 起步即可）、Python 3.10+、一个域名。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 准备配置（填入你自己的支付通道参数，格式见示例文件）
cp config.example.json config.json

# 3. 本地先跑起来看看（默认监听 8080）
python3 app.py
```

**正式上线**：

1. 用 systemd 托管进程（仓库里附了备份服务的 unit 示例可参考），
   让程序开机自启、崩溃自动拉起
2. 前面套一层 Caddy（或 Nginx）反代到 `127.0.0.1:8080` 并签发 HTTPS 证书
3. 卖家后台入口：`https://你的域名/admin/login`，用管理员账号登录后
   即可处理订单、填写交付、管理商品与库存、给客户储值、回复客服消息
4. 数据库就是目录里的 `store.db` 一个文件，仓库附带
   `backup_db.py` + systemd timer，可实现每日自动备份

**日常运营**：新订单会有推送提醒 → 后台把订单标「已支付/待充值」
的逐个处理 → 填交付内容 → 标「已完成」；退款/失败在后台一键操作，
库存与已售会自动同步。

> ⚠️ `config.json`（含支付密钥）与 `store.db`（含客户数据）已在
> `.gitignore` 中排除，**切勿提交到公开仓库**。
