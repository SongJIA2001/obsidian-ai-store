# 曜石 AI · OBSIDIAN — AI 会员代充 / 成品号小店

一个独立部署的数字商品小店（线上站点：[muse798.com](https://muse798.com)）：
访客浏览商品 → 注册/登录 → 下单付款 → 店主在卖家后台人工交付，
客户在「我的订单」实时看进度。全站任何环节都不索要客户的账号密码。

## 功能

- 邮箱注册/登录（PBKDF2 + 会话 Cookie + CSRF）、免登录查单、找回密码闭环
- 易支付（码支付）支付宝通道：同步跳转 + 异步通知验签改单 + 主动查单兜底
- 卖家后台：订单处理、交付内容填写、确认已收款（平台漏单时用）、
  删除订单、商品管理（改名/改价/库存/上下架/新增商品）
- 储值钱包：支付宝储值、首充赠送、余额支付、余额退款自动返还
- 会员等级：普通/白银/黄金/铂金/黑金五级，消费或充值达标自动升级，
  下单按等级打折，店主可手动调整
- 成本/利润统计（仅后台可见）、人工在线客服（站内聊天 + 未读提醒）
- 新订单 Bark 推送通知店主；数据库每日自动备份
- 客户侧 10 种语言：简体/繁體/English/日本語/한국어/Français/
  Deutsch/Español/Português/Русский（卖家后台固定中文）
- 商品卡质保徽章、公告轮播、法律三页（隐私/条款/Cookie）

## 技术

- Python 3 标准库 + `cryptography`（见 requirements.txt），无框架
- SQLite 单文件数据库（store.db，自动生成）
- 服务端渲染 HTML/CSS/JS，无构建步骤
- 部署：systemd 服务监听 8080，Caddy 反代 + HTTPS

## 本地运行

```bash
pip install -r requirements.txt
cp config.example.json config.json   # 填入你自己的支付与站点配置
python3 app.py
```

> ⚠️ `config.json`（含支付密钥）与 `store.db`（含客户数据）已在
> `.gitignore` 中排除，切勿提交到公开仓库。
